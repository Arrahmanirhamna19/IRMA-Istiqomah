# IRMA-Istiqomah
IRMA (Ikatan Remaja Masjid) merupakan wadah bagi generasi muda untuk belajar, berkarya, dan berkontribusi dalam memakmurkan masjid. Melalui kegiatan keagamaan, sosial, pendidikan, dan kreativitas, IRMA membangun remaja yang berakhlak, aktif, bertanggung jawab, dan bermanfaat bagi masyarakat.
